This is the build that can receive things sent from the Mac.

If you already set this phone up and saw no inbox: two reasons, both fixed or explained
here. The inbox only ever showed a badge when something was waiting, so an empty one
looked like a missing feature — there is now a permanent "Sent to you" row under Family,
at zero as well. And if you had already been sending from a Mac, this phone could not
claim the identity doing the sending: "this is me" was offered only for identities nobody
had used yet, which is exactly backwards for somebody adding their own second device.
Any admin but yourself can be claimed now.

Claim before you send yourself anything, or the phone will be a different person with the
same name and nothing addressed to the Mac's David will arrive here.

Set it up first — Home -> ... -> Family:
1. Type your name. It is what your approvals get signed with, so the other admin can see
   who decided what.
2. Choose the shared folder. It has to be the same iCloud Drive folder the Mac is pointed
   at, shared with the other admin in Files. No app can create or share that folder for
   you, which is why this step is by hand.
3. Add people. Minors are who you send to; admins are the other grown-ups. A person added
   as the wrong one can be fixed later rather than removed and re-added.

Then, on the Mac, drag a channel or a video from the Saved panel onto somebody's device in
the Dispatch board. What happens on this phone depends on who it is set up as:

- An ADMIN's phone gets a tray badge on Home with a count. Open it, swipe to keep what you
  want, or Keep All. Things sent to you are a suggestion and you can ignore them.
- A MINOR's phone just gets them. They appear on the Home shelves and approved videos
  download by themselves. No inbox: a child did not ask for any of it.

Everything the inbox shows is drawn from the decision itself — it makes no request to
YouTube for any of it, which is the same reason a minor's phone works with no network.

Worth trying:
- Set two devices to the same folder and watch somebody appear on both after a sync.
- Send a video to a minor's phone and check it downloads on its own.
- Un-send it from the Mac (the same menu, or drag). On a minor's phone the file should be
  deleted; on an admin's it should not, because an admin's own library is never swept.
- Send the same thing twice. The second time should change nothing.
- Anything already on your shelves will not appear in the inbox — that is the filter
  working, not an empty inbox.

Also in this build: a ... menu on every video and channel row for save, download and send.
Minor Mode gained the guardian/minor identities the family needs, with a migration that
fails closed — a phone that was locked stays locked and asks an admin which minor it is,
rather than unlocking itself on upgrade.

Known limits: only a phone or tablet pulls what it is sent. The Mac has no inbox yet, so
sending to a Mac records it but that machine will not fetch it. And Minor Mode is a switch
inside this app — it does not stop anyone opening Safari; that is Screen Time's job.
