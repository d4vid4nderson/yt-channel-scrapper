The app is now YT Parent Command Center. On the home screen it reads "Command Center".

Nothing moved on disk. The name you see and the folder the library lives in are
deliberately two different things, so renaming the app did not hide your saved channels
the way the earlier bundle-id change did. If your shelf was there before this build, it
should still be there after it.

New: Send to Device. Home -> ... -> Send to Device. Tick the exact channels and videos you
want somebody else to have, and it exports just those through the share sheet — AirDrop,
Messages, whatever. The other phone imports it with Home -> ... -> Import Library.

Read the warning on that screen before ticking a channel. A channel gives them everything
in it, including whatever it uploads next. A video gives them that one video and nothing
else. Videos-only is the tighter choice.

Still worth re-testing from the last build, because this is the first one most of you will
actually have:

- Minor Mode. Home -> ... -> Minor Mode, set a PIN, turn it on. Search disappears,
  downloading goes with it. The lock button top right is the way back and costs the PIN.
- iCloud. Save a channel, delete the app, reinstall from TestFlight. It should come back
  on first launch. This is the one that matters most — it is the thing that failed.
- Export and import now ask for channels, videos or both, and import tells you what is in
  the file before you choose.

Worth trying:
- Check the app name and icon look right, on the home screen and in Settings.
- Send two videos to another device and confirm no channels arrive with them.
- Import the same file twice. The second time should say there is nothing new.
- Four wrong PINs is free; the fifth starts making you wait.

Not in this build, so do not go looking for it: the guardian shelf — shared approvals
between two parents through an iCloud Drive folder — is written and tested but has no
screens yet. There is nothing to see.

Known and deliberate: Minor Mode is a switch inside this app. It does not stop anyone
opening Safari or the real YouTube; that is Screen Time's job. And videos in Minor Mode
currently stream, which means YouTube's ads. The ad-free guarantee arrives with the shelf,
which plays only downloaded files.
